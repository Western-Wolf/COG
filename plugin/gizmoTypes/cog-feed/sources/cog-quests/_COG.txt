# COG quests feed icon rules
# Location: Data/SKSE/Plugins/COG/gizmoTypes/cog-feed/sources/cog-quests/
# Last wins: later-named *.txt files and later lines override earlier matches.
#
# Grammar:
#   <kind> <op> `<needle>` [<op> `<needle>` ...] = Section/icon.svg
# Ops: equals, notequals, contains, notcontains (case-insensitive; spaces in ` ` matter)
#
# Kinds:
#   name            — raw quest title or objective text (NOT "Quest Started:" / "Completed:" chrome)
#   form            — plugin:hex pin (same as inventory/effects), e.g. Skyrim.esm:0003372B
#   questtype       — CK Type: none, mainquest, magesguild, thievesguild, darkbrotherhood,
#                     companionsquest, miscellaneous, daedric, sidequest, civilwar,
#                     dlc01_vampire, dlc02_dragonborn
#   queststatus     — started | completed | failed (quest banners only)
#   objectivestatus — started | completed | failed (objective lines only)
#
# Objective lines still carry the parent quest's form + questtype.
# When no rule matches, Quests source Status / Objectives icons are used.
